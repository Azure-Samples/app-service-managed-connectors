# Reporting security issues

Report suspected security vulnerabilities privately to the
[Microsoft Security Response Center](https://msrc.microsoft.com/create-report).
Do not report vulnerabilities through public GitHub issues.

For reporting guidance and contact information, see
[Microsoft's security reporting policy](https://www.microsoft.com/msrc/faqs-report-an-issue).
Do not include access tokens, OAuth consent URLs, mailbox contents, or private
deployment configuration in public issues or pull requests.
